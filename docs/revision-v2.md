# Revision: an explorable personal portfolio

The user rejected the first build for resembling a sales website and requested more interesting interactions and separate sections. This changes the information architecture and visual metaphor.

Replace the long landing page with five separate, directly addressable chapter views: `#/`, `#/journey`, `#/work`, `#/notes`, `#/hello`. Keep the factual content, real photography, project source links, keyboard-accessible controls and reduced-motion support.

The entry point is Mai’s personal working desk: an isometric 3D miniature with a notebook, project laptop, portrait frame and postcard. Each meaningful object opens one chapter; visible HTML labels offer equivalent keyboard and touch navigation. A quiet global chronology sits just below the navigation, oldest to newest, and opens the corresponding career chapter.

Journey is a page-turning career journal. Work is a project folder archive with an index and a full story view, replacing the sales-card grid. Notes is a personal scrapbook with real portrait, education, award and working principles. Hello is a postcard with direct email, copy, LinkedIn and the original CV.

No sales hero, no giant benefit headlines, no proof strip, no conversion banner, no repetitive sections or generic CTA pills. Personality comes from the physical objects and genuine career material.
