# Visual direction

Six standalone section references were generated with the built-in image generator: hero, journey, selected work, approach, about and contact. See `docs/design-references/` and `docs/design-prompts.json`.

## Interpretation

- Hero: translate the sculptural blue ribbon, orbit labels, pale grid, generous white space, restrained navigation and mixed sans/italic-serif hierarchy into real DOM and a live Three.js scene. The ribbon represents one continuous thread across different roles.
- Journey: retain the horizontal oldest-to-newest stations and the photo/story detail panel. Update the final station to the verified TikTok role. Use real source photos instead of the generated sample portrait and location.
- Work: preserve four stories, large evidence metrics and blue accents; use actual project photography from the supplied portfolio instead of generated conceptual projects or invented results. Break the grid rhythm with staggered tiles.
- Approach: three expandable numbered principles, each connected to documented experience. Decorative bars and nodes are abstract, without invented chart values.
- About: retain the personal keepsake feeling, blue sticker, education and languages; replace the illustrative identity card with Mai’s real portrait.
- Contact: retain the bold cobalt field, white display type and clear contact action; adapt copy to a person already at TikTok.

Typography: DM Sans and Instrument Serif. Colors: white #fbfcfe, ink #1b2c43, cobalt #245fe7, pale blue #eef4ff. Desktop maximum content width 1296px; mobile gutters 20px. Three motion speeds: 180ms feedback, 350ms interaction, 850ms section reveal. Disable ongoing movement for reduced motion or the persistent motion toggle.

User brief authorises implementation and iteration. All copy must follow the source record; generated design reference text is not biographical evidence.
