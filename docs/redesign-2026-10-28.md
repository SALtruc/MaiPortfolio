# Business portfolio refinement — 28 October 2026

## Direction and audit

The existing React / TypeScript / Three.js site had genuine photographs and detailed project narratives, but the home page communicated only a greeting and four destinations. Its large desk camera crop hid some of the scene and competed with the greeting. Project images had little physical framing, and Project Stories used metric markup that did not match its stylesheet.

The revision preserves the white-and-blue palette, Instrument Serif / DM Sans pairing, existing routes, authentic photographs and factual source record. The opening now explains Mai's analytical and interpersonal strengths. Her current role is presented as an early learning chapter. Metrics retain their documented meaning: CTM's revenue contribution is a share, and personal Careers Fair conversations are distinguished from overall event attendance.

## Reference interpretation

The following are the user's supplied inspiration sources, consulted on 28 October 2026. They inform the visual direction; no paid templates, proprietary component source or third-party portfolio work are bundled in this repository.

- [Scrolltide](https://www.scrolltide.co/components): physical card decks and focused framed photography informed the layered project gallery.
- [ThreeUI](https://threeui.com/): spatial UI and component depth informed restrained pointer tilt and the nested live desk. The supplied `/browse?sort=recent` URL was unavailable through the text browser, so the public homepage and indexed component categories were consulted.
- [Inspora](https://www.inspora.design/) and [Landbook](https://land-book.com/): considered hierarchy, large editorial type and an asymmetric image/text composition.
- [Details carousel examples](https://www.details.so/inspo/category/carousel): a prominent active project with direct controls, swipe support and keyboard access.
- [SceneAI](https://sceneai.art/): section composition and deliberate transitions rather than continuous decorative effects.
- [Create with Swift](https://www.createwithswift.com/): approachable, readable content presentation. The website remains in the existing React stack.
- [Kitbitz](https://kitbitz.art/): supplied illustration reference; the text browser returned no extractable content. No Kitbitz assets are used. Genuine project photography remains the focus.

## Implementation

The home page includes a business introduction, interactive miniature desk within nested frames, an experience ribbon, a five-project gallery, personal working principles, recognition and contact. Gallery selections expose the correct case-study link and documented metrics. All changes are local to the existing app, with no new product dependencies.

The project collection retains native vertical scrolling with a sticky photo stage on desktop and photograph-first articles on mobile. Case covers, evidence, process tabs, journey photographs, the about page and contact postcard share the refined surface treatment. Four desk destinations become a clear two-column control group on phones so small projected labels do not overlap.

Motion uses transforms and opacity, short custom easing curves, entry reveals, coalesced pointer updates and the existing Three.js scene. Frame tilt is restricted to fine pointers; reduced motion and the manual pause control stop animation. The desk remains lazy-loaded, stops rendering when offscreen, and retains its static fallback and HTML navigation if WebGL fails.

## Verification

`npm run build` validates TypeScript and produces the static bundle. `scripts/verify-redesign.py` exercises the live browser at desktop and 320px, 390px and 768px widths. It checks gallery wrapping and pagination, keyboard navigation, a real browser touch swipe, project links, process tabs, evidence dialogs and Escape, mobile menu behavior, postcard contact details, reduced motion and a simulated WebGL failure. The JSON report and screenshots are in `docs/verification/`.

The existing Three.js vendor bundle exceeds Vite's default 500 kB advisory threshold. It is already split into a separate lazy-loaded chunk; no additional animation library was introduced.
